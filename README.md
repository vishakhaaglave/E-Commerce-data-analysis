# E-Commerce Data Analysis

## Project Overview
This project analyzes an e-commerce sales dataset to discover business insights using Python.

## Objectives
- Analyze sales performance
- Identify profitable categories
- Study regional sales
- Understand customer segments
- Visualize business trends

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Jupyter Notebook

## Dataset
Sample Superstore Dataset

## Visualizations
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Profit Analysis
- Correlation Heatmap

## Project Structure
dataset/
images/
notebooks/

## How to Run
1. Clone the repository
2. Install requirements
3. Open the notebook
4. Run all cells
